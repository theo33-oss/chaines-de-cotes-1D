CHAINES DE COTES 1D - MODE D'EMPLOI

Deux façons de l'utiliser :

A. Dans le navigateur, sans rien installer
   https://theo33-oss.github.io/chaines-de-cotes-1D/

B. Sur le bureau Windows (dossiers PDF et Word, enregistrement sur le disque)
   1. Télécharger ChainesDeCotes_Installation_x.y.z.exe
      https://github.com/theo33-oss/chaines-de-cotes-1D/releases/latest
   2. Le lancer. Si Windows affiche "Windows a protégé votre ordinateur" :
      Informations complémentaires > Exécuter quand même.
   3. L'installation se fait pour vous seul (pas de droits d'administrateur)
      et crée une icône sur le Bureau. Rien d'autre à installer : Python
      et les bibliothèques sont inclus.
   Désinstaller : Paramètres de Windows > Applications > Chaînes de cotes 1D.

Pour les développeurs, depuis le code source : installer Python 3.12
(https://www.python.org/downloads/, "py launcher" coché), puis double-cliquer
sur 1_Ouvrir_application.bat (il installe les bibliothèques au premier
lancement, 5 à 10 minutes, environ 1 Go, Internet nécessaire).

Vos données restent sur votre ordinateur : rien n'est envoyé sur Internet.

Outil pédagogique et d'aide à la cotation : les résultats doivent
être vérifiés avant tout usage réel. Limites connues : LIMITES.md.
